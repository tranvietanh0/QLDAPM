# 3. PM - Project Plan

## Team 5 nguoi
1. PM: scope, WBS, sprint, Jira/Trello, risk, meeting, release.
2. BA: requirement, use case, user story, acceptance criteria.
3. FE: React UI, routing, form validation, API integration.
4. BE: database, REST API, authentication, business rules.
5. Tester: test plan, test cases, API/UI testing, bug report, regression.

## WBS
1. Initiation
   - Chot scope, stakeholder, technology.
2. Analysis
   - Requirement, use cases, user stories.
3. Design
   - ERD, API contract, wireframe.
4. Development
   - Backend API.
   - Frontend UI.
5. Testing
   - Functional, API, permission, negative test.
6. Release
   - Fix bug, seed demo data, prepare demo script.
